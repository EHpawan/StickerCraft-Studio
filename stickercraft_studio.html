How to Publish & Link Live Razorpay

Complete guide to process real payments live on the web

1 Get Your Razorpay Key ID

  1. Log in to your Razorpay Dashboard.
  2. Complete your **KYC verification** and bank account details for payouts.
  3. Navigate to **Settings > API Keys** and click **Generate Key ID**.
  4. Copy your `rzp_live_...` Key ID (or `rzp_test_...` for test mode).

2 Update the Key in Code

In this file (`index.html`), find line **~410** inside the `initiateRazorpay` function:

key: "rzp_test_YourKeyHere"

Replace `"rzp_test_YourKeyHere"` with your actual Razorpay Key ID (e.g., `"rzp_live_abc123xyz"`).

3 Publish Live For Free

You can host this standalone file in 1 click for free using any of these platforms:

  • Netlify Drop: Go to netlify.com/drop and drag & drop this file.
  • Vercel: Import the repository directly or upload via Vercel CLI.
  • GitHub Pages: Upload to a repository and enable GitHub Pages in Settings.
